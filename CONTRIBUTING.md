# CONTRIBUTING.md—how a change reaches this document

This is a public reference document with a single owner (HetCreep), licensed **CC BY-NC-ND 4.0**
(`LICENSE`). **NoDerivatives** means nobody else may publish an adapted version of it, and a pull
request that edits the text is an adaptation. So the ordinary open-source loop of fork, edit and
pull request is not the model here. Sending one is not rude; it is just something that cannot be
merged.

What is wanted is narrower and more valuable: **evidence that something in it is wrong**, such as a
wrong exemplar figure, a broken formula, or a source that has gone out of date.

## How to send a correction

**Open an issue:** https://github.com/HetCreep/GachaRateDesignDatum/issues

The owner decides what changes. A report must meet the conditions the published contributing page
states:

- **Every proposal needs a real source.** A floating "best practice" with no source cannot be
  accepted. Name the source, and quote the wording you found there.
- **A proposal that touches a BASE value goes through adversarial review** before it is merged into
  the rules (`docs/governance.md`).

## What happens to an accepted change

- **It reaches the published site through this repository.** The owner makes the change here, and
  the site follows.
- **It gets a version and a changelog entry.** The owner records it in [`CHANGELOG.md`](CHANGELOG.md),
  which follows Keep a Changelog and Semantic Versioning. A BASE value change always gets a new
  version number (`docs/governance.md`).
- **A released entry is immutable.** It is never edited after the fact. A correction gets a new
  entry (`CHANGELOG.md`).

## What will not be accepted

- **Rewordings, restructuring, and style.** The expression is the part the licence protects, and it
  is the owner's.
- **A proposal with no source.** See above.

## A licence request

You may share the document with credit. Commercial use or adaptation needs written permission from
the owner (`docs/license.md`). For that, open an issue or approach the owner through
**github.com/HetCreep**.
