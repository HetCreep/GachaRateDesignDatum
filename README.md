# Gacha Rate Design Datum

**A reference document for setting gacha rates, pity and price without guessing the numbers.** It is
written in Thai.

📖 **Read it at
[https://hetcreep.gitbook.io/hetcreep-docs/gacharatedesigndatum](https://hetcreep.gitbook.io/hetcreep-docs/gacharatedesigndatum).**
The reading copy is split into pages (Reference, Explanation, Guides, Governance); the single-file
source is [`GACHA-RATE-DESIGN-LOCK-PUBLIC.md`](GACHA-RATE-DESIGN-LOCK-PUBLIC.md).

---

## What it is

**เอกสารนี้ตอบคำถามเดียว: เรต pity ราคา ควรเป็นเท่าไหร่ และคุณรู้ได้ยังไงว่าไม่ได้มั่ว**

คำตอบไม่ใช่ตัวเลข แต่เป็น **กฎ** ที่ทำให้ตัวเลขตกลงมาเอง — และเป็น **งานวัดจากเกมจริง 6 เกม**
ที่เผยแพร่เรตของตัวเองไว้ ไม่ใช่ "best practice" ลอย ๆ

## Version

The current version and every past change are in [`CHANGELOG.md`](CHANGELOG.md), which follows Keep a
Changelog and Semantic Versioning. A released entry is not edited after the fact; a correction gets a
new entry.

## Report a correction

Evidence that something in the document is wrong is the most useful thing a reader can send. Open an
issue at https://github.com/HetCreep/GachaRateDesignDatum/issues with the location, the source and the
wording you found there. [`CONTRIBUTING.md`](CONTRIBUTING.md) says what is wanted and what cannot be
accepted.
