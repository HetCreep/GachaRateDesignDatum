title: Contributing
---

เอกสารนี้เป็น reference สาธารณะ ไม่ใช่ living software repo ที่เปิด pull request ตรง ๆ ได้

เสนอแก้ไข (ตัวเลข exemplar ผิด, สูตรพัง, แหล่งอ้างอิงล้าสมัย) ทำได้โดยติดต่อเจ้าของเอกสาร (HetCreep) ตรง ๆ เงื่อนไข:

- ทุกข้อเสนอต้องมีแหล่งอ้างอิงจริง ห้าม "best practice" ลอย ๆ ที่หาแหล่งไม่ได้
- ข้อเสนอที่กระทบตัว BASE ต้องผ่าน adversarial review ก่อนรวมเข้ากฎ (ดู [Governance](../governance.md))
- การแก้ทุกครั้งจะบันทึกใน [CHANGELOG.md](https://github.com/HetCreep/GachaRateDesignDatum/blob/main/CHANGELOG.md) ของ repository
